# DXF → 注文伝票CSV 変換ツール

DXFファイルをドラッグ＆ドロップするだけで、注文伝票形式のCSVを自動生成するWindowsツールです。

## 使い方

1. `DXF変換ツール.exe`（またはPythonスクリプト）にDXFファイルをドラッグ＆ドロップ
2. 同じフォルダに `元のファイル名_注文伝票.csv` が生成されます

## 出力CSVの列

| 列名 | 内容 |
|------|------|
| 工事マーク | 工事識別記号（例: `(A-1)`） |
| 材質 | 鋼材種別（例: `SM490`） |
| 厚み | 板厚（mm） |
| 縦 | 幅（mm） |
| 横 | 長さ（mm） |
| 図形マーク | 図形識別記号 |
| 枚数 | 枚数 |
| 穴径 | 孔径情報 |

## 読み取りルール

- 図面の**上から下**・各行は**左から右**の順に処理します
- `<マーク>n枚` 形式のテキストを図形マークとして認識します
- `PL-厚みx縦x横` 形式のテキストからサイズを抽出します

## 動作環境

- Windows 10 / 11
- Python 3.9 以上（スクリプトとして実行する場合）
- 依存ライブラリ: 標準ライブラリのみ（追加インストール不要）

## ビルド方法

```powershell
pip install pyinstaller
pyinstaller "DXF変換ツール.spec"
```
